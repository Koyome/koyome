SECTION 04

Notes from the quiet hours

这里是一段示例正文，用来判断线稿在真实页面里是否会干扰阅读。线条应退到纸面后面，只留下一点呼吸感。

每个设计出四个文件：deco_x.svg（日间动画）、deco_x_dark.svg（夜间动画，预烘焙换色不用滤镜反色）、 deco_x_still.svg / deco_x_still_dark.svg（剥离 CSS 后的无动画静帧）。
动画只使用 transform / opacity，元素自带静帧基准值，所以去掉 CSS 后仍是同一张构图；SVG 内部还写了 @media (prefers-reduced-motion: reduce) 兜底。但实测 Chromium 不会把 prefers-reduced-motion 传进 <img> 引用的 SVG 文档（内联 SVG 才生效），因此接入页面时应由 JS 判断 matchMedia('(prefers-reduced-motion: reduce)') 切换到 _still 版本。
质感体系：全图只有一个光源（左上），每根线都吃同一道渐变；环体有真实厚度 + 受光边/暗边；纸面上有一道压印投影； 金属带是多段各向异性渐变；颗粒由确定性微点构成（不用任何滤镜，避免逐帧重绘）。
三维模型（晶体二十面体 / 环面线圈 / 玻璃立方 / 双螺旋，纯 CSS3D 无库）见 tools/k3d-preview.html。
本预览页仅在本地 tools/ 目录，不会被推送上线。
